Runs on Kali, Windows, WSL2

KALI LINUX (RECOMMENDED)

  • Docker Engine + Compose plugin already ship with Kali.
  • docker compose up --build in this folder.
  • Open http://127.0.0.1:8777; the image contains the Go/Python/apt toolchain.
  • Native mode works too: python3 server.py, then install tools from the Tools tab.

WINDOWS 11 / WSL2

  • Docker Desktop with the WSL2 backend: same docker compose up --build.
  • Native Windows: install Python 3.12 from python.org (not the Store stub), then python server.py.
  • Go-based tools install with go install; the release scripts are bash and expect WSL.
  • Keep the port bound to 127.0.0.1; the API can spawn agents.
